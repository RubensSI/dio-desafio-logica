# 🚀 Desafio de Lógica: Classificador de Nível de Herói

Este projeto é parte de um desafio da **DIO (Digital Innovation One)** focado em lógica de programação utilizando JavaScript.

## 📝 Objetivo
O objetivo é criar uma lógica que classifique o nível de um herói com base na sua quantidade de experiência (XP).

## 🛠️ Tecnologias
- **JavaScript**
- **Node.js** (para execução local)

## 🎮 Níveis de Classificação
| XP | Nível |
| :--- | :--- |
| Menor que 1.000 | Ferro |
| Entre 1.001 e 2.000 | Bronze |
| Entre 2.001 e 5.000 | Prata |
| Entre 5.001 e 7.000 | Ouro |
| Entre 7.001 e 8.000 | Platina |
| Entre 8.001 e 9.000 | Ascendente |
| Entre 9.001 e 10.000 | Imortal |
| Maior ou igual a 10.001 | Radiante |

## 🚀 Como executar
1. Certifique-se de ter o [Node.js](https://nodejs.org/) instalado.
2. Clone o repositório.
3. No terminal, execute:
   ```bash
   node index.js
   ```
